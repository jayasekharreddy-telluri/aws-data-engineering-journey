Create the following S3 buckets:

* yt-data-pipeline-bronze-ap-south-1-dev

  * Create Lifecycle Management
  * Rule Name: archiveOldRawData

* yt-data-pipeline-silver-ap-south-1-dev

* yt-data-pipeline-gold-ap-south-1-dev

Enable Versioning on all buckets.
