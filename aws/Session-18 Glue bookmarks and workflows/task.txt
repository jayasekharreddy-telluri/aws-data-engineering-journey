# Task 1 — Enable Job Bookmarks

## What We Did

* Opened Glue Job
* Enabled:

  ```text
  Job bookmark → Enable
  ```
* Updated ETL script to support bookmarks

## Purpose

Enable incremental processing instead of full reload every run.

## Important Learning

Bookmarks process only new S3 files after previous successful execution.

---

# Task 2 — Added transformation_ctx to Glue Reads/Writes

## What We Did

Added:

```python
transformation_ctx='source_orders'
```

to all:

* from_catalog()
* write_dynamic_frame()

## Purpose

Allow Glue to track bookmark state.

## Important Learning

Without `transformation_ctx`, bookmarks do not work.

---

# Task 3 — Added job.commit()

## What We Did

Added:

```python
job.commit()
```

at end of ETL script.

## Purpose

Save bookmark state after successful run.

## Important Learning

Without `job.commit()`, bookmark state is never updated.

---

# Task 4 — Handled No-New-Data Scenario

## What We Did

Added logic:

```python
if df.count() == 0:
    print("No new data")
    job.commit()
    sys.exit(0)
```

## Purpose

Prevent Glue job failure when no new files arrive.

## Important Learning

Incremental jobs must exit gracefully when no data exists.

---

# Task 5 — Fixed Bookmark Argument Error

## What We Did

Resolved error:

```text
GlueArgumentError:
--job_bookmark_option required
```

by removing manual argument handling and using Glue Job Bookmark setting correctly.

## Purpose

Allow Glue to manage bookmarks automatically.

## Important Learning

Bookmarks should be enabled from Job Details, not manually through script arguments.
