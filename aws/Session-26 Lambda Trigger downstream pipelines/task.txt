# Task 1 — Environment Variables

## What We Did

* Opened Lambda Configuration
* Added Environment Variables

```text
BUCKET_NAME = my-test-bucket
ENVIRONMENT = dev
```

* Read variables inside Lambda using:

```python
os.environ.get()
```

* Printed values in CloudWatch Logs

## Purpose

Store configuration outside code.

## Important Learning

```text
Code + Config should be separated

Bucket Name → Env Variable
Environment Name → Env Variable
```

# Task 6 — Configure DLQ

## What We Did

Opened:

```text
Lambda
 ↓
Asynchronous Invocation
```

Configured:

```text
Retry Attempts = 2
DLQ = lambda-day2-dlq
```

## Purpose

Prevent event loss.

## Important Learning

```text
Fail
 ↓
Retry
 ↓
Retry
 ↓
DLQ
```

### Error Faced

```text
Execution role does not have
permission to SendMessage
```

### Fix

Added SQS permission to Lambda role.

```text
AmazonSQSFullAccess
```

# Final Architecture Understanding

```text
S3 Upload
     ↓
Lambda Trigger
     ↓
Read Config
(Environment Variables)
     ↓
Read Secrets
(Secrets Manager)
     ↓
Validate Data
     ↓
Handle Errors
     ↓
Retry If Needed
     ↓
DLQ If Failed
     ↓
Enrich Data
(Pandas Layer)
     ↓
Trigger Glue Job
     ↓
ETL Processing
```
